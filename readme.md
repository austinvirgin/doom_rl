# Doom Reinforced Learning

This is a demonstration of learning to use Reinforced Learning Neural Networks


## Instructions for Build and Use

Steps to build and/or run the software:

1. [Download this virtual environment](https://drive.google.com/file/d/1D1FhhSu-u6bs1IHun5JYeCtlHs1S9wGn/view?usp=sharing)
2. Once the virtual environment is added nothing should need to be added

Instructions for using the software:

1. [Download the model](https://drive.google.com/file/d/1qnbjmGv5jf618-YtGwa_f8Av0ICtnQyD/view?usp=sharing)
2. Add the model to a pair of folders called train/train_defend
3. Go to the file named run.ipynb
4. Select the vizdoom310 kernel
5. Press run all

## Development Environment 

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* vizdoom
* random
* time
* numpy
* gymnasium
* cv2
* stable_baselines3
